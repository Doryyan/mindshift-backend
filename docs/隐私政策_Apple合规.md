# 念转（MindShift）隐私政策

**版本：v1.0 | 生效日期：2026年7月1日**

## 一、引言

北京汇成家科技有限公司（注册地址：北京市昌平区北清路1号院6号楼3层2单元310，以下简称"我们"）深知个人信息对您的重要性，并致力于保护您的隐私。本隐私政策旨在向您清晰说明，在您使用"念转（MindShift）"（以下简称"本产品"）时，我们如何收集、使用、存储、共享和保护您的个人信息。

**使用本产品即表示您已阅读、理解并同意本隐私政策所述的信息处理方式。如您不同意本政策的任何条款，请停止使用本产品。**

## 二、我们收集的信息

我们仅收集为实现产品功能所必需的信息，具体如下。

> **App Store 隐私标签对齐**：以下数据类别与 App Store Connect 中「App 隐私」标签保持一致。

### 2.1 您主动提供的信息（Data Linked to You）

| 数据类别 | 具体内容 | 收集目的 | Apple 隐私标签分类 |
|----------|----------|----------|---------------------|
| 账户信息 | 电子邮箱、昵称、性别（选填） | 创建和管理您的账户 | Contact Info |

### 2.2 自动收集的信息（Data Not Linked to You）

| 数据类别 | 具体内容 | 收集目的 | Apple 隐私标签分类 |
|----------|----------|----------|---------------------|
| 使用数据 | 课程学习进度、训练完成情况、功能使用频率 | 优化产品体验（仅聚合分析） | Usage Data |

- 我们不收集精确位置信息
- 我们不收集通讯录、照片库（除非您主动上传）

## 三、信息存储与加密

### 3.1 数据分类存储

| 数据类别 | 存储位置 | 加密方式 |
|----------|----------|----------|
| 账户信息 | 服务器 | bcrypt 哈希（密码）+ TLS 传输加密 |
| 学习进度/训练评分 | 服务器 | TLS 传输加密 |
| 信念日记内容 | 本地加密 + 用户可选云端同步 | AES-256-GCM 客户端加密 |
| 角色扮演对话记录 | 本地加密 + 用户可选云端同步 | AES-256-GCM 客户端加密 |
| 情绪/状态日志 | 仅本地存储 | AES-256-GCM 客户端加密 |

### 3.2 加密说明

- 敏感心理数据采用 AES-256-GCM 算法在客户端加密，加密密钥由用户密码通过 PBKDF2 派生
- 加密密钥永不上传到服务器
- 服务器端仅存储已加密的数据块（Blob），无法解密
- 您可以选择是否将已加密的敏感数据同步到云端以实现多设备访问

## 四、信息使用与共享

### 4.1 我们如何使用您的信息

- 提供、维护和改进本产品服务
- 生成个性化的 NLP 训练反馈和能力评估
- 向您发送服务相关通知（训练提醒、打卡提醒等）
- 进行数据分析和产品优化（使用聚合/匿名数据）
- 检测和防止欺诈、滥用行为

### 4.2 我们如何共享您的信息

**我们不出售您的个人信息。** 在以下情况下，我们可能共享您的信息：

| 共享场景 | 共享内容 | 说明 |
|----------|----------|------|
| AI 服务提供商 | 训练输入文本（去标识化） | 调用智谱 AI API 进行训练评估和对话生成 |
| 崩溃监控服务 | 错误日志 | 通过 Bugly 收集崩溃信息以修复 Bug |
| 法律要求 | 依法必须提供的信息 | 法院命令、政府要求等法定情形 |
| 业务转移 | 全部用户数据 | 公司合并、收购或资产出售时 |

### 4.3 集成的第三方服务

| 第三方 | 用途 | 隐私政策链接 |
|--------|------|-------------|
| 智谱 AI（GLM-4-Flash） | AI 训练评估与对话生成 | https://open.bigmodel.cn/privacy |
| Apple IAP | 会员订阅支付 | https://www.apple.com/legal/privacy/ |
| Bugly | App 崩溃监控 | https://privacy.qq.com/ |

### 4.4 我们不会做的事

- 不会将您的敏感心理数据（信念日记、对话记录、情绪日志）以明文形式出售或共享
- 不会使用您的训练数据训练第三方 AI 模型
- 不会在未经您明确同意的情况下将您的个人信息用于本政策未载明的目的

## 五、数据存储与安全

### 5.1 数据存储

- **存储地点**：中华人民共和国境内
- **保留期限**：我们仅在实现收集目的所需的期限内保留您的个人信息。账户注销后，所有关联数据将被永久删除

### 5.2 安全措施

我们采取以下技术与组织措施保护您的个人信息：

- **传输安全**：全站 HTTPS/TLS 加密
- **存储安全**：敏感数据客户端 AES-256-GCM 加密，服务器端加密存储
- **认证安全**：JWT 令牌认证 + bcrypt 密码哈希
- **访问控制**：最小权限原则，内部人员权限分级
- **监控审计**：异常访问检测和日志审计

## 六、您的数据权利

根据《中华人民共和国个人信息保护法》，您享有以下权利：

| 权利 | 行使方式 |
|------|----------|
| **查阅权** | 通过 App「个人中心 → 数据管理 → 查看我的数据」查阅您的全部个人数据 |
| **更正权** | 通过「个人中心 → 编辑资料」修改账户信息 |
| **删除权** | 通过「个人中心 → 数据管理 → 清除全部数据」一键删除本地和云端全部数据。此操作不可恢复 |
| **导出权** | 通过「个人中心 → 数据管理 → 导出数据」将个人数据导出为 JSON 格式文件 |
| **撤回同意** | 通过「个人中心 → 设置 → 隐私设置」撤回数据收集授权。撤回不影响撤回前已基于同意进行的数据处理 |
| **注销账户** | 通过「个人中心 → 设置 → 注销账户」永久删除账户及关联数据 |

您也可以通过发送邮件至 support@hcjworld.com 行使上述权利。我们将在收到请求后 3 个工作日内响应。
